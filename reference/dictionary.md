# Data dictionary

Descriptions of every column in the `pbp`, `possessions` and
`lineup_stats` tables.

## Usage

``` r
dictionary
```

## Format

A tibble with one row per column:

- table:

  Table the column belongs to.

- column:

  Column name.

- type:

  R type.

- description:

  What the column holds.

- seasons:

  Seasons the column is available for.
